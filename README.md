# Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, education, and professional profile. The website features a clean user interface, dark mode support, smooth scrolling navigation, typing animations, and a functional contact form powered by EmailJS. 

## 🚀 Live Features

- Responsive design for desktop, tablet, and mobile devices
- Dark/Light mode toggle with local storage persistence
- Animated typing effect on the hero section
- Smooth scrolling navigation
- Mobile-friendly navigation menu
- About Me section
- Education and Skills showcase
- Project portfolio section
- Contact form integration using EmailJS
- Social media links (GitHub & LinkedIn)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- EmailJS
